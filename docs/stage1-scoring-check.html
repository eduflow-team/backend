Stage1 채점 (정답 − 리소스 감점)

최종 = max(0, 정답점수 − 리소스감점)

  • 정답점수: 정규화 후 완전일치 → 100 / 아니면 0
  • 리소스감점: 교사 default보다 키운 top_k·chunk_size만 (최대 약 30점). temperature 제외
  • 제출 2회, 정답 공개는 마감 후

예시 (default = 50 / 2 / 1.0)
